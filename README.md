# EMAVIAS - Sistema de Gestión Administrativa

Sistema web para EMAVIAS (Empresa Municipal de Asfaltos y Vías — La Paz, Bolivia).

## Tecnologías
- HTML5, CSS3, JavaScript puro (sin frameworks)
- localStorage para persistencia de datos
- Importación/Exportación CSV

## Páginas
- index.html — Login
- dashboard.html — Dashboard principal
- obras.html — Registro de Obras
- form-obra.html — Formulario de Obra
- produccion.html — Producción Asfáltica
- horas-extra.html — Horas Extra
- boletas-salida.html — Boletas de Salida
- cotizaciones-externos.html — Cotizaciones Externos
- cotizaciones-gamlp.html — Cotizaciones GAMLP
- precios.html — Precios y Tarifas GAMLP
